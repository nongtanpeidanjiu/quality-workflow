# 通用工作流程插件 安装说明（Codex 版）

版本 0.4.0 · 适用于 ChatGPT 桌面版里的 Codex（Mac 和 Windows）

> Windows 版按官方文档编写，**没有在 Windows 真机上测试过**。遇到问题请反馈。

---

## 一、适用范围

| 在哪里用 | 是否支持 |
|---|---|
| ChatGPT 桌面版的 Codex 模式 | 支持 |
| ChatGPT 桌面版的 Work 模式 | 不支持。它在云端运行，Codex 官方不支持在那里运行插件的钩子 |
| ChatGPT 桌面版的 Chat 模式、网页版、手机版 | 不支持。它们不操作你电脑上的文件 |

需要先装好 ChatGPT 桌面版，并至少打开过一次。**除此之外，电脑上不需要预先装任何东西：** 没有 Python 会自动装一份免安装版；不需要 git 和 Node。

---

## 二、安装

1. 下载 `quality-workflow-codex-0.4.0.zip`。
2. 打开 ChatGPT 桌面版，进入 Codex，新建一个任务，把压缩包拖进对话框，一起发送：

```
帮我安装这个插件，按压缩包里《给智能体的安装步骤》做。
```

3. 看到“安装成功”后，**下面三步要你自己做：**
   1. 完全退出并重新打开 ChatGPT 桌面版，进入 Codex。
   2. 打开 **Settings > Hooks**（或点输入框附近的“Review hooks”），找到 **Quality Workflow**，把它的钩子全部信任并打开。
   3. 新建一个任务，随便发一句话，比如“你好”。智能体会自动运行安装自检，直到看到“全部通过。插件已经生效。”

### 为什么要“信任钩子”

这个插件靠“钩子”把关：智能体每次写文件、执行命令、准备结束时，Codex 会先运行插件里的检查程序。Codex 规定，插件带的钩子必须由用户审核信任后才会运行。**不信任，插件装上了但关卡是关着的，而且 Codex 不会提醒你。**

所以插件做了一层保护：智能体每次开工前会先检查钩子是否在运行，没在运行就停下来，告诉你去信任，不会在关卡失效的情况下继续干活。

---

## 三、不用智能体，自己在终端里安装

解压压缩包后：

- Mac：打开“终端”，运行 `sh <解压位置>/quality-workflow-codex-0.4.0/install.sh`
- Windows：打开 PowerShell，运行 `powershell -NoProfile -ExecutionPolicy Bypass -File <解压位置>\quality-workflow-codex-0.4.0\install.ps1`

装完同样要做第二节第 3 步。

## 四、更新

**不会在后台自动更新。** 原因是 Codex 规定：插件内容只要有变化，之前对钩子的信任就失效，必须重新信任。如果在后台悄悄更新，关卡会在你不知情的情况下失效。

所以更新是这样的：

1. 插件每天在后台查一次有没有新版本（先查 GitHub，查不到再查 jsDelivr 镜像）。
2. 有新版本时，在新任务里提醒你。
3. 你对智能体说“**更新插件**”，它会下载新版本、核对文件、重新安装。
4. 更新完成后，**到 Settings > Hooks 里重新信任 Quality Workflow 的钩子**，然后新建任务。

不想收到新版本提醒，可以设置环境变量 `QFLOW_NO_UPDATE_CHECK=1`。

## 五、常见问题

**问：装好了，但它没有先复述、也没有拦我写文件。**
答：多半是钩子没有信任。到 Settings > Hooks 里检查 Quality Workflow 的钩子是否都已信任并打开，然后新建一个任务。

**问：智能体说“钩子没有在运行，流程关卡是失效的”，然后停下了。**
答：这是插件的保护在起作用。按它说的去信任钩子，再新建任务即可。插件刚更新过时一定会遇到这一步。

**问：删除、对外发布这类动作，它为什么先拒绝再来问我？**
答：Codex 的钩子不能弹确认框，只能拒绝。所以遇到难以收回的动作，插件会先拒绝，让智能体把要做的事和后果告诉你。你明确同意后，它再执行一次才会放行。

**问：项目里多出来的 `.flow` 文件夹是什么？**
答：是任务记录，包括需求、计划、确认记录和检查报告。任务结束后可以删除。

**问：安装时说没有 Python，自动安装也没成功。**
答：通常是网络原因。按提示里给出的办法手动安装 Python，再运行一次安装脚本。

## 六、卸载

1. 在 Codex 的插件页面卸载 Quality Workflow，并移除 `quality-workflow-codex` 市场。
2. 删除 Codex 配置目录里的 `agents/independent-checker.toml`（Mac 在 `~/.codex/`，Windows 在 `%USERPROFILE%\.codex\`）。
3. 可选：删除用户目录下的 `.quality-workflow` 文件夹，以及各项目里的 `.flow` 文件夹。

**不要手动删除 Codex 自己的配置文件夹，** 里面还有你的其他设置。

---

## 七、遇到问题怎么反馈

让智能体运行安装自检（对它说“运行 quality-workflow 的安装自检”），把完整输出连同下面的信息发到 GitHub 仓库的 Issues：

```
电脑系统：Mac / Windows（版本号）
ChatGPT 桌面版版本：
插件版本：0.4.0
卡在哪一步：
自检结果（原样粘贴）：
发生了什么、你期望发生什么：
```
