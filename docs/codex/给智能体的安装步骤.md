# 给智能体的安装步骤（Codex 版）

这份文件是写给 ChatGPT 桌面版里的 Codex 智能体看的。用户把压缩包交给你、让你安装这个插件时，按下面做。

## 步骤

1. 把压缩包**完整解压**到一个临时文件夹。解压后应该有一个 `quality-workflow-codex-0.4.0` 文件夹，里面有 `install.sh`、`install.ps1` 和 `marketplace` 文件夹。

2. 运行安装脚本：

   - Mac：

     ```
     sh "<解压位置>/quality-workflow-codex-0.4.0/install.sh"
     ```

   - Windows：

     ```
     powershell -NoProfile -ExecutionPolicy Bypass -File "<解压位置>\quality-workflow-codex-0.4.0\install.ps1"
     ```

3. 脚本会自己完成下面这些事，不需要你另外操作，也不需要电脑上预先装任何东西：
   - 检测 Python。没有就自动下载一份免安装版，放在用户目录下的 `.quality-workflow/python`，不改系统设置，不需要管理员权限。
   - 找到 ChatGPT 桌面版自带的 Codex 程序。不需要 git、Node，也不需要命令路径里有 `codex`。
   - 卸载旧版本，安装新版本、独立检查员和命令入口。

4. **把脚本的输出原样告诉用户。**

5. 输出里有“安装成功”时，**务必把最后三步原样告诉用户，并说明第 2 步只能由用户自己做**：
   - 完全退出并重新打开 ChatGPT 桌面版，进入 Codex。
   - 打开 Settings > Hooks（或点输入框附近的“Review hooks”），找到 Quality Workflow，把它的钩子全部信任并打开。
   - 新建一个任务，随便发一句话，按提示完成安装自检。

   不信任钩子，插件装上了也不起作用。你不能替用户做这一步，也不要用任何参数或改配置文件的办法绕过它。

## 遇到问题时

- **输出里有“没有可用的 Python，自动安装也没有成功”：** 通常是网络原因。按输出里列出的办法装好 Python，其中的命令你可以直接执行。装好后再运行一次安装脚本。
- **输出里有“找不到 ChatGPT 桌面版自带的 Codex 程序”：** 把输出原样告诉用户。输出里给了手动安装的办法。
- **输出里有“安装没有完成”：** 把原因原样告诉用户。
- **提示没有权限、或写入被拒绝：** 原样告诉用户，由用户决定。

## 不要做的事

- 不要修改压缩包里的任何文件。
- 不要修改插件的规则文件、钩子配置来让安装或自检通过。
- 不要替用户信任钩子，不要修改 Codex 的配置文件。
- 不要替用户卸载这个插件以外的东西。
