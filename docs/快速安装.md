# 通用工作流程插件 快速安装

让 WorkBuddy 自己安装，三步就好。Mac 和 Windows 都适用。

---

## 第 1 步：把压缩包发给 WorkBuddy

1. 打开 WorkBuddy，**新建一个任务**。
2. 把 `quality-workflow-0.3.3.zip` **拖进对话框**。

## 第 2 步：说一句话

和压缩包一起发送：

```
帮我安装这个插件，按压缩包里《给智能体的安装步骤》做。
```

它会自己解压、检测环境、卸载旧版本、安装新版本。电脑上缺 Python 时，它会自动装一份免安装版，不改系统设置。

等它回复下面这句话，就表示装好了：

```
安装成功：quality-workflow 0.3.3 已安装并启用。
```

## 第 3 步：新建任务，完成自检

1. **完全退出并重新打开 WorkBuddy，再新建一个任务。** 必须是新任务，刚才那个任务不会加载新装的插件。
2. **Windows 用户先检查一下：** 打开“专家·技能·连接器 → 技能 → 套件”，找到 quality-workflow，确认开关是打开的。没有打开就手动打开，再完全退出并重新打开一次 WorkBuddy。
3. 随便发一句话，比如“你好”。
4. 智能体会自动提醒运行安装自检。按它的提示操作，直到看到：

```
全部通过。插件已经生效。
```

自检通过一次后，以后就不会再提醒了。

---

## 遇到问题

| 情况 | 怎么办 |
|---|---|
| 第 2 步提示没有可用的 Python | 自动安装没成功，多半是网络原因。让它按提示里给出的办法安装，装好后再说一遍“帮我安装这个插件” |
| 第 2 步提示“安装没有完成” | 把提示原样记下来，然后按《安装说明》里的“方法二”手动安装 |
| 第 2 步提示“插件已安装，但没有启用” | WorkBuddy 运行时占用了设置文件，Windows 上较常见。完全退出 WorkBuddy，等 10 秒再打开，然后到“专家·技能·连接器 → 技能 → 套件”确认 quality-workflow 的开关已打开 |
| 第 3 步新任务里没有出现自检提醒 | 多半是插件没有启用。到“专家·技能·连接器 → 技能 → 套件”把 quality-workflow 的开关打开，完全退出并重新打开 WorkBuddy，再新建任务 |
| 自检有项目没通过 | 让智能体按自检给出的建议修好环境，修完再运行一次 |
| 其他问题 | 把自检的完整结果发给分享插件给你的人 |

更详细的用法、更新和卸载方法，见压缩包里的《安装说明》。
