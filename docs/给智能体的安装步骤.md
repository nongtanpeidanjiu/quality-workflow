# 给智能体的安装步骤

这份文件是写给 WorkBuddy 的智能体看的。用户把压缩包交给你、让你安装这个插件时，按下面做。

## 步骤

1. 把压缩包**完整解压**到一个临时文件夹。解压后应该有一个 `quality-workflow-0.3.2` 文件夹，里面有 `install.mjs` 和 `marketplace` 文件夹。

2. 用 Node 运行安装脚本：

   ```
   node "<解压位置>/quality-workflow-0.3.2/install.mjs"
   ```

   如果提示找不到 `node` 命令，改用 WorkBuddy 自带的 Node：
   - Mac：`~/.workbuddy/binaries/node/versions/<版本号>/bin/node`
   - Windows：`%USERPROFILE%\.workbuddy\binaries\node\versions\<版本号>\node.exe`

3. 脚本会自己完成下面这些事，不需要你另外操作：
   - 检测环境。缺 Python 时，自动下载一份免安装版，放在用户目录下的 `.quality-workflow/python`，不改系统设置，不需要管理员权限。
   - 卸载旧版本。
   - 安装并启用新版本。

4. **把脚本的输出原样告诉用户。**

5. 输出里有“安装成功”时，告诉用户：请完全退出并重新打开 WorkBuddy，然后新建一个任务，随便发一句话。新任务会自动提醒运行安装自检。

## 遇到问题时

- **输出里有“还差一步：这台电脑没有可用的 Python”：** 自动安装没有成功，通常是网络原因。按输出里列出的办法装好 Python，其中的命令你可以直接执行。装好后再运行一次 `install.mjs`。
- **输出里有“安装没有完成”：** 把原因原样告诉用户，并告诉用户可以按《安装说明》里的“方法二”手动安装。不要去翻 WorkBuddy 的程序文件找别的办法。
- **提示没有权限、或写入被拒绝：** 原样告诉用户，由用户决定。

## 不要做的事

- 不要修改压缩包里的任何文件。
- 不要修改插件的规则文件、hook 配置来让安装或自检通过。
- 不要改动其他插件的设置。
- 不要替用户卸载这个插件以外的东西。
